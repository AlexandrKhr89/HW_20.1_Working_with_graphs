# HW 20.1. Робота з графами

У цьому завданні вам потрібно буде створити клас для роботи з графами та реалізувати базові операції над ними.

1. Створіть клас для виконання завдання:
2. a. Створіть клас Graph, який буде представляти граф та містити методи для додавання вершин, додавання ребер, видалення вершин, видалення ребер, а також для перевірки чи існує вершина чи ребро у графі.
3. Реалізуйте методи для роботи з графом:
4. a. Метод addVertex(int vertex), що додає вершину до графу.
5. b. Метод addEdge(int source, int destination), що додає ребро між двома вершинами.
6. c. Метод removeVertex(int vertex), що видаляє вершину з графу.
7. d. Метод removeEdge(int source, int destination), що видаляє ребро між двома вершинами.
8. e. Метод hasVertex(int vertex), що перевіряє чи існує вершина у графі.
9. f. Метод hasEdge(int source, int destination), що перевіряє чи існує ребро між двома вершинами у графі.
10. Створіть методи, щоб продемонструвати роботу з графом:
11. a. Створіть граф та додайте до нього вершини та ребра.
12. b. Перевірте роботу методів додавання, видалення та перевірки вершин та ребер.
13. Залийте виконаний проект в свій GitHub репозиторій, посилання на який зазначте в LMS
